Slår sammen gdp og pop til gdp_pop. Lage kategorivariablene n2 (NUTS2), n1 (NUTS1) og nc (Country). Gjør om gdp til Euro istedenfor mill. Euro. Beregner gdp_pc (GDP per capita i NUTS3 regioner). Filtrerer ut observasjoner der vi mangler data.

gdp_pop <- gdp |> 
  left_join(pop, by = join_by(Geo_Kode, Geo_Navn, År)) |> 
  mutate(
    # gdp per capita
    gdp_pc_n3 = gdp_n3 / pop_n3,
    n2 = str_sub(Geo_Kode, start = 1, end = 4),
    n1 = str_sub(Geo_Kode, start = 1, end = 3),
    nc = str_sub(Geo_Kode, start = 1, end = 2),
    .before = Geo_Navn
  ) %>% 
  filter(complete.cases(.))

Beregning av Gini

Beregner Gini for NUTS2 regioner (gini_n2). Finner også antall NUTS3 i hver NUTS2, total gdp i NUTS2 regioner (gdp_n2) og total befolkning i NUTS2 regioner (pop_n2). Beregner ogs GDP per Capita for NUTS 2 regioner.

gdp_pop_n2 <- gdp_pop  %>%  
  group_by(n2, År) |> 
  summarise(
    gini_n2 = dineq::gini.wtd(gdp_pc_n3, weights = pop_n3),
    num_n3 = n(),
    gdp_n2 = sum(gdp_n3),
    pop_n2 = sum(pop_n3),
    gdp_pc_n2 = gdp_n2 / pop_n2,
    .groups = "drop"
  )

Legger gini_n2, num_n3, gdp_n2, pop_n2 og gdp_pc_n2 til gdp_pop. De NUTS3 regionene som er i samme NUTS2 region vil ha samme verdi for disse variablene.

gdp_pop <- gdp_pop |> 
  left_join(gdp_pop_n2, by = join_by(n2, År))

Gjør tilsvarende for NUTS1 og Country så har vi alle data. Regner Gini utfra gdp_pc_n3. Merk at num_n2 er antall NUTS2 regioner i NUTS1 regionene
